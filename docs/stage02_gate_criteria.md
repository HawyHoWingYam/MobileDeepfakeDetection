# AWARE-NET Stage 02 门控标准文档 (Stage-Gate Criteria)

## 📋 **文档概述**

本文档定义了AWARE-NET Stage 02 (异构专家模型) 的完整门控验收标准，确保在进入Stage 03之前，空间专家和生成专家都达到预期性能，并展现明显的互补性。

**版本**: 1.0.0
**最后更新**: 2025-09-23
**适用阶段**: Stage 02 → Stage 03 过渡

---

## 🎯 **门控验收哲学**

### **异构专家系统原则**
- **专业分工**: 每个专家在特定领域必须显著超越通用基线
- **互补性验证**: 专家间相关性 < 0.7，错误模式差异明显
- **系统效率**: 双专家并行推理不超过单专家2倍开销
- **学术严谨**: 所有创新必须有统计学意义的验证

### **三层验收架构**
1. **技术门槛** (Technical Gates): 功能性和性能要求
2. **学术门槛** (Academic Gates): 创新性和科学严谨性要求
3. **系统门槛** (System Gates): 可用性和可扩展性要求

---

## 🔴 **关键决策门槛 (Critical Decision Gates)**

### **Gate 2.1: 空间专家专业化验证**
**必须通过条件**: 空间偽影检测AUC ≥ 0.95，相比基线提升 ≥ 5%
**目标条件**: 边缘融合偽造检测AUC ≥ 0.98
**失败后果**: 启动风险缓解 - 调整专家设计或使用通用强模型

### **Gate 2.2: GenConViT重建假设验证**
**必须通过条件**: 真实图像SSIM ≥ 0.85，偽造图像 < 0.70
**目标条件**: GAN/Diffusion样本检测AUC ≥ 0.95
**失败后果**: 放弃重建任务，转为纯判别式变体

### **Gate 2.3: 异构互补性验证**
**必须通过条件**: 专家预测相关系数 < 0.7
**目标条件**: 互补错误率 ≥ 30% (一专家错另一对)
**失败后果**: 重新设计专家架构或差异性强化训练

| 验证项目 | 具体要求 | 测试方法 | 接受标准 |

## ⛔ **强制停止条件**

遇到以下情况必须立即停止，重新设计：

1. **空间专家专业化失败**: 在空间偽影检测上无法超越通用基线 ≥ 3%
2. **GenConViT重建假设错误**: 重建质量差异不明显，生成检测无优势
3. **异构互补性不足**: 专家预测相关系数 > 0.8，错误模式高度相似
4. **系统效率不可接受**: 双专家推理时间 > 200ms 或内存使用 > 12GB
5. **基线改进不明显**: 两个专家相比Stage 01都无明显优势 (< 2%)
6. **学术创新不足**: 异构专家系统相比单一强模型无理论或实践优势
