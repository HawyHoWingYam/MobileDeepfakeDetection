# AWARE-NET Stage 01 门控标准文档 (Stage-Gate Criteria)

## 📋 **文档概述**

本文档定义了AWARE-NET Stage 01 (SupCon快速过滤器) 的完整门控验收标准，确保在进入Stage 02之前，所有技术、学术和系统要求都得到满足。

**版本**: 1.0.0
**最后更新**: 2025-09-22
**适用阶段**: Stage 01 → Stage 02 过渡

---

## 🎯 **门控验收哲学**

### **严格验收原则**
- **学术严谨性**: 所有创新必须有统计学意义的改进
- **技术可行性**: 满足移动端部署的性能约束
- **系统完整性**: 级联系统集成无缝衔接
- **风险控制**: 早期验证避免大规模资源浪费

### **三层验收架构**
1. **技术门槛** (Technical Gates): 功能性和性能要求
2. **学术门槛** (Academic Gates): 创新性和科学严谨性要求
3. **系统门槛** (System Gates): 可用性和可扩展性要求

---

## 🔴 **关键决策门槛 (Critical Decision Gates)**

### **Gate 1: 小规模消融验证**
**必须通过条件**: SupCon vs BCE基线改进 ≥ 1% AUC
**目标条件**: SupCon vs BCE基线改进 ≥ 3% AUC
**失败后果**: 立即激活Plan B (Enhanced BCE) 或 Plan C (Focal Loss)

### **Gate 2: 架构性能验证**
**必须通过条件**: 推理时间 ≤ 50ms/image, 内存 ≤ 2GB
**目标条件**: 推理时间 ≤ 30ms/image, 内存 ≤ 1.5GB
**失败后果**: 架构优化或模型压缩

### **Gate 3: 级联效率验证**
**必须通过条件**: 过滤率 ≥ 90%, 假阴性率 ≤ 5%
**目标条件**: 过滤率 ≥ 95%, 假阴性率 ≤ 3%
**失败后果**: 阈值策略重新设计

## 📊 **技术门槛详细标准 (Technical Gates)**

### **1. 模型性能要求**

| 指标 | 最低要求 | 理想目标 | 测试方法 | 失败处理 |
|------|----------|----------|----------|----------|
| **验证集AUC** | ≥ 0.90 | ≥ 0.95 | 5折交叉验证 | 超参数调优/架构调整 |
| **F1-Score** | ≥ 0.85 | ≥ 0.90 | 平衡测试集 | 阈值优化/损失函数调整 |
| **校准ECE** | ≤ 0.05 | ≤ 0.03 | 温度缩放后 | 校准方法改进 |
| **校准MCE** | ≤ 0.10 | ≤ 0.05 | 可靠性图验证 | 多变量校准 |

### **2. 基线改进要求**

| 对比基线 | 最低改进 | 理想改进 | 统计要求 | 验证方法 |
|----------|----------|----------|----------|----------|
| **vs BCE基线** | +3% AUC | +5% AUC | p < 0.05 | 配对t检验 |
| **vs Stage 0** | +3% AUC | +5% AUC | 95% CI不重叠 | Bootstrap置信区间 |
| **特征分离度** | +20% | +30% | 类间/类内距离比 | 特征空间分析 |

### **3. 性能效率要求**

| 指标 | 最低要求 | 理想目标 | 测试环境 | 测量方法 |
|------|----------|----------|----------|----------|
| **推理延迟** | ≤ 50ms | ≤ 30ms | GPU环境 | 100次平均 |
| **内存峰值** | ≤ 2GB | ≤ 1.5GB | 批量推理 | 内存监控 |
| **模型大小** | ≤ 100MB | ≤ 50MB | 压缩前 | 文件大小 |
| **吞吐量** | ≥ 20 fps | ≥ 30 fps | 连续处理 | 吞吐量测试 |

## 🎓 **学术门槛详细标准 (Academic Gates)**

### **1. 统计严谨性要求**

| 验证项目 | 具体要求 | 测试方法 | 接受标准 |
|----------|----------|----------|----------|
| **统计显著性** | p-value < 0.05 | 双侧t检验 | 拒绝零假设 |
| **置信区间** | 95% CI | Bootstrap方法 | CI不包含0 |
| **效应量** | Cohen's d > 0.5 | 标准化差异 | 中等到大效应 |
| **多重比较校正** | Bonferroni校正 | FDR控制 | 校正后p < 0.05 |

### **2. 创新性验证要求**

| 创新维度 | 验证标准 | 评估方法 | 文档要求 |
|----------|----------|----------|----------|
| **范式转换** | 理论框架完整 | 数学推导验证 | 完整理论文档 |
| **方法新颖性** | 文献对比分析 | 相关工作调研 | 创新点总结 |
| **实证贡献** | 消融研究完整 | 逐步添加组件 | 详细消融报告 |
| **可重现性** | 代码+数据+配置 | 独立复现测试 | 复现指南 |

### **3. 特征空间分析要求**

| 分析维度 | 评估指标 | 计算方法 | 接受标准 |
|----------|----------|----------|----------|
| **类别分离度** | 分离评分 > 2.0 | 类间距离/类内距离 | 明显分离 |
| **特征质量** | 可视化清晰度 | t-SNE/UMAP | 视觉可分 |
| **几何结构** | 流形分析 | 拓扑分析 | 结构化表示 |
| **泛化能力** | 跨数据集一致性 | 多数据集验证 | 方差 < 0.02 |

report = evaluator.evaluate_comprehensive(
    rapid_filter, test_loader, baseline_results
)

# 门槛验证

if not gate_passed:
    print("❌ Stage Gate验证失败")

    print("✅ 所有Stage Gate通过，准备进入Stage 2")
