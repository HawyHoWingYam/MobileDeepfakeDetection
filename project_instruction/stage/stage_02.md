### **任務 2.2：GenConViT生成結構專家**
**學術目標**：實現創新的生成式-判別式混合模型，並驗證其在生成式偽造檢測上的獨特優勢

**核心假設驗證**：
生成式檢測方法是否真的比判別式方法更好？特別是對GAN/Diffusion生成的偽造？

**模型架構**：
- **ConvNeXt-Swin混合層**：結合局部和全局特徵提取
- **自編碼器組件**：通過重建檢測生成式不一致性  
- **雙變體支持**：ED（編碼器-解碼器）和VAE（變分自編碼器）變體

**理論基礎**：
```
生成檢測原理：
真實圖像: I_real → Encoder → z → Decoder → I_reconstructed ≈ I_real
偽造圖像: I_fake → Encoder → z → Decoder → I_reconstructed ≠ I_fake

重建誤差 = MSE(I_input, I_reconstructed) + Perceptual_Loss(I_input, I_reconstructed)
```

**GenConViT vs 基線對比實驗**：
```python
comparison_focus = {
    'GAN生成樣本': 'StyleGAN, PGGAN等',
    'Diffusion生成樣本': 'Stable Diffusion等', 
    '傳統偽造': 'Face Swap, Reenactment',
    '重建質量': 'SSIM, LPIPS指標'
}
```

**實現任務**：
- [ ] **GenConViT架構實現**：
  ```python
  class GenConViT(nn.Module):
      def __init__(self, variant='ED'):  # 'ED' or 'VAE'
          # ConvNeXt特徵提取器
          self.convnext_encoder = ConvNeXt(depths=[3,3,9,3])
          # Swin Transformer全局建模
          self.swin_transformer = SwinTransformer(depths=[2,2,6,2])  
          # 自編碼器組件
          if variant == 'VAE':
              self.encoder = VAEEncoder()
              self.decoder = VAEDecoder()
          else:
              self.encoder = Encoder()
              self.decoder = Decoder()
          # 雙任務頭
          self.classifier = nn.Linear(768, 1)  # 分類任務
          self.reconstructor = self.decoder      # 重建任務
  ```

- [ ] **雙任務訓練策略**：
  - 聯合損失函數設計：
  ```python
  # 組合損失函數
  total_loss = α × classification_loss +  # BCE分類損失
               β × reconstruction_loss +   # MSE重建損失  
               γ × perceptual_loss +       # VGG感知損失
               δ × kl_divergence_loss      # KL散度（VAE變體）
  
  # 損失權重: α=1.0, β=0.5, γ=0.3, δ=0.1
  ```
  - 多階段訓練策略：預訓練重建任務 → 聯合微調 → 分類微調

- [ ] **訓練腳本 train_stage2_genconvit.py**：
  - 實現雙變體訓練（ED和VAE）
  - 集成Hugging Face預訓練模型（Deressa/GenConViT）
  - 實現custom collate function處理重建任務
  - 添加重建質量監控和可視化

- [ ] **生成偽影專用處理**：
  - 設計保持生成結構的數據增強
  - 實現重建誤差的多尺度分析
  - 添加注意力機制突出關鍵重建區域

- [ ] **生成專家獨特價值驗證**：
  - 與階段0基線在GAN生成樣本上的對比
  - 重建任務是否真的帶來檢測優勢
  - 計算開銷vs性能收益分析

**期望性能vs基線**：
- 總體性能：AUC > 0.93，相比基線提升 ≥ 3%
- 生成式偽造：GAN/Diffusion樣本AUC > 0.95，相比基線提升 ≥ 8%
- 重建質量：真實圖像SSIM > 0.85，偽造圖像< 0.70
- **關鍵驗證**：必須在GAN/Diffusion偽造上顯著超越基線，證明生成式檢測的價值

## 📋 **風險應對計劃**

### **如果空間專家不如預期怎麼辦？**
#### **應對策略階梯**
1. **輕微不達標** (提升1-2%)：
   - 調整空間偽影專用的數據增強
   - 優化grad-CAM引導的注意力機制
   - 嘗試不同的空間頻率分析方法

2. **中度不達標** (專家≈基線)：
   - 重新審視「空間專家」的假設
   - 嘗試其他CNN架構（RegNet, ConvNeXt）
   - 考慮組合多種空間檢測技術

3. **嚴重不達標** (專家<基線)：
   - 放棄空間專家概念，使用更強的通用模型
   - 重新分析數據集中的空間偽影特徵
   - **Plan B**: 直接使用兩個不同的通用強模型

### **如果GenConViT不如預期怎麼辦？**
#### **核心問題分析**
GenConViT的假設是：重建任務能幫助檢測。如果這個假設不成立：

1. **重建任務無效** (重建質量差異不明顯)：
   - 調整重建損失函數權重
   - 嘗試不同的感知損失（LPIPS、CLIP等）
   - 考慮對抗性重建損失

2. **生成檢測假設錯誤** (重建好但檢測差)：
   - 分析重建誤差與檢測性能的相關性
   - 嘗試將重建誤差作為額外特徵而非主要信號
   - **Plan B**: 放棄重建，直接訓練判別式變體

### **如果異構互補性不足怎麼辦？**
如果兩個專家太相似（相關係數>0.8）：

1. **強化差異性**：
   - 調整訓練數據分佈，讓專家看到不同樣本
   - 使用不同的損失函數（一個用SupCon，一個用Focal）
   - 引入對抗性訓練讓專家學習不同特徵

2. **重新設計專家**：
   - 考慮時間維度：靜態專家 vs 動態專家
   - 考慮頻域維度：高頻專家 vs 低頻專家
   - **Plan B**: 使用完全不同的架構組合

### **替代專家方案**
- **空間專家替代**: RegNetY, ConvNeXt, Swin Transformer
- **生成專家替代**: 純判別模型 + 多尺度特徵
- **全新專家**: 頻域分析專家, 時序一致性專家

**決策原則**: 如果專家系統無法顯著超越單一強基線，考慮簡化為單模型+更好的訓練策略

## 💡 **核心學術洞察**

階段二的本質是**異構專家系統的構建**。不同於傳統的單一模型方法，我們通過訓練專精於不同檢測維度的專家模型，實現了「專業分工」的檢測策略。

**關鍵洞察**：
1. **不同架構天然適合不同類型的偽造檢測**
2. **專家化訓練比通用化訓練更能深入挖掘特定偽造特徵**  
3. **異構互補性是高性能融合系統的基礎**
4. **生成式檢測方法為深偽檢測提供了新的視角**

這種異構專家設計不僅提升了單個專家的性能，更重要的是為構建魯棒的融合系統提供了理論基礎和實踐驗證。
