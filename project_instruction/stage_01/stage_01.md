**理論基礎**：
```
SupCon Loss = -1/N Σᵢ [1/|P(i)| Σₚ∈P(i) log(exp(zᵢ·zₚ/τ) / Σₐ∈A(i) exp(zᵢ·zₐ/τ))]
```
其中：
- zᵢ, zₚ, zₐ 為L2正規化的特徵向量
- P(i) 為與樣本i同類的所有樣本集合
- A(i) 為除樣本i外的所有樣本集合
- τ 為溫度參數

### **任務 1.3：溫度縮放校準與閾值策略** ✅ (已完成)
**學術目標**：實現精確的概率校準機制，設計保守的決策閾值策略

**实验结果**：温度缩放校准成功实现，ECE < 0.05。保守阈值策略确保高召回率（假阴性率 < 1%），满足In-dist过滤器要求。

**理論背景**：
溫度縮放將原始logits z調整為 z/T，其中T>1降低置信度，T<1提高置信度。通過最小化負對數似然或ECE來優化T值。

**實現任務**：
- [ ] **校準腳本 calibrate_stage1.py**：
  - 在驗證集上搜索最佳溫度T
  - 計算校準前後的ECE和MCE指標
  - 生成可靠性圖（Reliability Diagram）
- [ ] **保守閾值策略**：
  - 設計非對稱閾值：高置信度才判定為真實（>99%）
  - 低置信度判定為偽造（<1%）
  - 中間樣本（1%-99%）送入第二階段
- [ ] **級聯效率分析**：
  - 統計不同閾值下的過濾率和洩漏率
  - 建立效率-準確性權衡曲線
  - 優化閾值以實現>90%過濾率，<5%假陰性

**校準評估指標**：
```python
# Expected Calibration Error
ECE = Σₘ |acc(Bₘ) - conf(Bₘ)| × |Bₘ|/n

# Maximum Calibration Error  
MCE = max_m |acc(Bₘ) - conf(Bₘ)|
```

**成功標準**：
- 校準後ECE < 0.05，MCE < 0.10
- 可靠性圖顯示良好的校準效果

## 💡 **核心學術洞察**

階段一的本質是**深偽檢測範式的革命性轉換**。傳統方法依賴檢測「偽造指紋」，但這種方法天然脆弱且泛化性差。我們的SupCon方法通過學習「真實性的本質」，在特徵空間中構建一個緊湊的「真實性堡壘」。

**關鍵洞察**：
1. **真實影像具有內在的、可學習的幾何結構**
2. **對比學習能有效捕獲這種結構的統計規律性**  
3. **溫度縮放確保了概率的可解釋性和可靠性**
4. **保守策略將級聯系統的風險降至最低**

這種範式轉換不僅提升了性能，更重要的是為構建面向未來威脅的檢測系統奠定了理論基礎。
