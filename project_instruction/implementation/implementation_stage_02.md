# Stage 2 Implementation Plan: 異構專家模型

## 📋 **Implementation Overview**

本階段構建兩個截然不同的專家模型，形成互補的檢測能力。EfficientNetV2-B3專精於空間域偽影檢測，GenConViT專精於生成結構分析，為後續的異構融合奠定基礎。核心策略是異構互補性、專家化訓練和特徵標準化。

---

## 🎯 **Core Implementation Tasks**

### **Task 2.1: EfficientNetV2-B3空間偽影專家設計**

#### **專家vs基線對比實驗設計**
在大規模訓練前，必須先回答核心問題：「這個專家真的比基線強嗎？在哪些方面強？」

**對比實驗設計策略**：
- **基線參照**: Stage 0的EfficientNetV2-B3基線模型
- **專家設計**: EfficientNetV2-B3 + 空間偽影專用優化
- **評估焦點**: 邊緣融合偽造檢測、紋理不一致檢測、空間頻率分析、跨數據集泛化
- **關鍵驗證**: 專家設計是否真的比通用基線更好？

#### **空間偽影專家設計理論**
**理論基礎**：
- 空間域偽造在邊緣融合、紋理不一致等方面存在可檢測特徵
- 較高解析度輸入(384x384)有利於保持細節信息
- 空間偽影需要專門的數據增強策略保持邊緣完整性
- Grad-CAM可視化空間注意力區域提高解釋性

**專家設計要點**：
- **架構優化**: 使用預訓練的EfficientNetV2-B3(ImageNet-21k → ImageNet-1k)
- **訓練策略**: SupCon訓練學習空間偽影判別特徵
- **數據增強**: 專門針對空間偽影的增強策略設計
- **學習率調度**: 漸進式學習率(backbone: 1e-5, classifier: 1e-3)

#### **空間偽影專用增強策略設計**
**增強策略理論**：
- 保持空間結構的增強: 小角度旋轉、水平翻轉
- 保持邊緣完整性: 高比例裁剪(0.9-1.0)
- 增強空間偽影敏感性: 輕微噪聲、動態模糊、顏色抖動
- 避免破壞空間偽影特徵的過度增強

#### **專家性能優化策略**
**優化理論框架**：
- **輸入分辨率**: 384x384保持細節信息
- **損失函數**: Focal loss處理難例樣本
- **正則化**: Label smoothing防止過擬合
- **可視化分析**: Grad-CAM分析模型注意力模式

### **Task 2.2: GenConViT生成結構專家設計**

#### **生成式檢測理論驗證**
**核心假設**: 生成式檢測方法是否真的比判別式方法更好？特別是對GAN/Diffusion生成的偽造？

**理論基礎**：
```
生成檢測原理：
真實圖像: I_real → Encoder → z → Decoder → I_reconstructed ≈ I_real
偽造圖像: I_fake → Encoder → z → Decoder → I_reconstructed ≠ I_fake

重建誤差 = MSE(I_input, I_reconstructed) + Perceptual_Loss(I_input, I_reconstructed)
```

#### **GenConViT架構設計理論**
**混合架構設計**：
- **ConvNeXt特徵提取**: 結合局部特徵提取優勢
- **Swin Transformer**: 全局建模和長程依賴捕獲
- **自編碼器組件**: 通過重建檢測生成式不一致性
- **雙變體支持**: ED(編碼器-解碼器)和VAE(變分自編碼器)變體

#### **雙任務訓練策略設計**
**聯合損失函數理論**：
- **組合損失**: 分類損失 + 重建損失 + 感知損失 + KL散度損失
- **權重平衡**: α=1.0(分類), β=0.5(重建), γ=0.3(感知), δ=0.1(KL)
- **多階段訓練**: 預訓練重建任務 → 聯合微調 → 分類微調

#### **生成偽影專用處理設計**
**處理策略理論**：
- 保持生成結構的數據增強設計
- 重建誤差的多尺度分析機制
- 注意力機制突出關鍵重建區域
- 重建質量監控和可視化系統

## 🚨 **Risk Mitigation Strategies**

### **Risk 2.1: 空間專家不如預期**
**風險描述**: 專家設計在空間偽影檢測上無法超越基線
**緩解策略**:
- **輕微調整**: 優化空間偽影專用數據增強策略
- **中度調整**: 嘗試其他CNN架構(RegNet, ConvNeXt)
- **重大調整**: 重新分析空間偽影特徵，考慮多技術組合
- **後備方案**: 使用更強的通用模型替代專家設計
**觸發條件**: 專家相比基線提升 < 2%

### **Risk 2.2: GenConViT生成檢測假設失敗**
**風險描述**: 重建任務無法有效幫助生成式偽造檢測
**緩解策略**:
- **損失函數調整**: 重新平衡重建和分類損失權重
- **感知損失優化**: 嘗試不同感知損失(LPIPS、CLIP等)
- **架構簡化**: 將重建誤差作為輔助特徵而非主要信號
- **後備方案**: 放棄重建任務，直接訓練判別式變體
**觸發條件**: 重建質量差異不明顯或檢測性能不提升

### **Risk 2.3: 異構互補性不足**
**風險描述**: 兩個專家預測模式太相似，缺乏互補價值
**緩解策略**:
- **差異性強化**: 調整訓練數據分佈，使用不同損失函數
- **對抗性訓練**: 引入對抗訓練讓專家學習不同特徵
- **專家重設計**: 考慮時間/頻域等其他差異化維度
- **後備方案**: 使用完全不同的架構組合
**觸發條件**: 專家預測相關係數 > 0.8

### **Risk 2.4: 計算資源超限**
**風險描述**: 雙專家系統記憶體和計算開銷過大
**緩解策略**:
- **模型壓縮**: 應用知識蒸餾和量化技術
- **並行優化**: 優化特徵提取和推理並行策略
- **架構簡化**: 減少模型複雜度保持關鍵功能
- **後備方案**: 單專家+更強基線的簡化方案
**觸發條件**: 記憶體使用 > 12GB 或推理時間 > 200ms

## 📊 **Quality Assurance Framework**

### **專家互補性驗證策略**
**驗證方法設計**:
- **錯誤分析**: 統計兩專家false positive/negative案例差異
- **相關性分析**: 計算專家預測的Pearson相關係數
- **專業領域驗證**: 各專家在專業/非專業領域的性能對比
- **融合潛力評估**: 簡單投票融合的性能上限分析

### **Testing Strategy**
**單元測試設計**:
- 專家模型架構正確性驗證
- 特徵提取功能一致性測試
- 重建任務數學正確性驗證
- 數據增強策略效果測試

**集成測試設計**:
- 雙專家並行推理穩定性測試
- 不同數據集兼容性測試
- 極端情況處理能力測試
- 長時間運行穩定性測試

### **Documentation Requirements**
**設計文檔**:
- 專家架構設計理念和數學原理
- 異構互補性理論分析
- 使用範例和最佳實踐指導
- 故障排除和調試指南

**技術文檔**:
- 雙專家系統實現細節
- 特徵提取和融合介面規範
- 性能優化技巧和調參指導
- 與其他階段的集成說明
